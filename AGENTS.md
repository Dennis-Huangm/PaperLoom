## Shell Environment

The host operating system is Windows.

Git Bash is installed and available as:

D:\Git\bin\bash.exe

Prefer Git Bash for shell commands.

When executing Unix-style shell commands from Windows, use:

bash -lc "<command>"

Prefer Bash/Unix syntax over PowerShell syntax unless PowerShell is explicitly required.
