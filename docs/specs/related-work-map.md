# 相关工作地图：可信关系、方向感知的发现与展示页改版

## Problem Statement

用户读到一篇感兴趣的论文后，希望找到下一批值得阅读的工作，同时看清参考文献和引用该论文的工作。现有图谱已经支持单篇入口、内容相似布局、引用叠加和详情，但候选覆盖、关系含义、数据状态及展示方式尚不足以支持这个判断。

源码检查和最小复现确认以下问题：

- 找不到达到相似度阈值的邻居时仍强制连边，完全没有词汇重合的论文也能产生分数为零的相似边并参与布局。
- 推荐来源产生的连线混入引用叠加层，用户无法仅凭“显示引用边”确信看到的是真实引用。
- 默认分别获取有限的参考文献、引用论文和推荐论文，直接用于展示；没有将候选预算与展示预算分开，推荐范围固定为计算机领域。
- 当前相似度反映图内标题和摘要的词汇重合。增加候选会改变权重，图间分数不能视作统一语义尺度；摘要缺失也没有充分呈现。
- 数据请求失败后可混用缓存和空结果，保存的图没有各来源的获取状态与时间。交叉引用部分失败时，缓存补全也缺少逐项完整性信息。
- 页面同步执行固定轮数的节点两两布局，扩大规模会增加主线程负担；全量标签、相似线和三栏内容竞争画布空间，详情缺少关联解释。
- 数据和页面分别发布，取消可能留下新数据与旧页面混用的结果；功能关闭、重试与取消的行为也需要与任务入口保持一致。

本规格不预设召回率或阅读效率的提升幅度。现有离线测试验证了基本生成与缓存回退，尚不足以证明关联质量或页面可用性。

## Solution

以“发现下一批值得阅读的相关论文”为主目标，以查看引用脉络为辅助能力。候选范围跟随研究方向，允许有依据的跨学科关联，保留无研究方向时以起点论文探索的能力。

用户输入起点论文后，系统在明确预算内收集候选，合并来源、检查方向边界，再选择相关且有差异的论文形成图谱快照。相似边表达内容相似，引用箭头表达真实引用，推荐来源展示在论文详情中。缺乏可靠关系的节点可以独立存在。

展示页改为浅色研究工作台：中央画布承担探索，左侧列表帮助快速选择，右侧详情解释“为什么相关”。默认突出选中论文及其邻居，减少全量标签和交叉线的干扰；用户可以切换到全图或引用视图。图谱库同步展示起点、方向、节点数量、更新时间和数据状态。

首版继续提供无需新增模型服务的本地计算路径，交付可解释的词汇相似度、候选筛选和可验证的引用关系。文本嵌入作为后续质量实验，不成为此次页面改版或生成流程的依赖。

## User Stories

1. As a 研究者, I want 从一篇起点论文生成相关工作地图, so that 我能决定接下来读什么。
2. As a 研究者, I want 地图使用当前研究方向的主题与明确条件, so that 结果服务于我的研究问题。
3. As a 跨学科研究者, I want 有依据的其他学科论文进入候选, so that 固定学科限制不会挡住相关工作。
4. As a 研究者, I want 没有研究方向时也能围绕起点探索, so that 临时阅读不要求先建立方向。
5. As a 研究者, I want 起点偏离当前方向时看到说明, so that 我理解候选较少的原因。
6. As a 研究者, I want 候选包含参考文献、引用论文和推荐服务发现的工作, so that 能从多种渠道寻找相关论文。
7. As a 研究者, I want 重复论文合并并保留所有来源, so that 多渠道命中不会挤占展示名额。
8. As a 研究者, I want 候选收集数量与画面节点数量分别受控, so that 图谱兼顾覆盖和可读性。
9. As a 研究者, I want 看到不同研究路线和新近工作, so that 高被引论文或近似重复工作不会占满地图。
10. As a 研究者, I want 收藏和不相关标记遵循研究方向隔离, so that 一个方向的判断不会影响另一个方向。
11. As a 研究者, I want 引用箭头明确从引用方指向被引用方, so that 我能正确理解参考关系。
12. As a 研究者, I want 分别控制相似关系与引用关系的展示, so that 能按当前任务阅读地图。
13. As a 研究者, I want 服务推荐来源与已证实关系分别说明, so that 我不会把推荐当作引用证据。
14. As a 研究者, I want 无可靠相似关系的论文保持独立, so that 页面不会为了连通而制造关联。
15. As a 研究者, I want 点击连线查看共同主题词或引用依据, so that 能判断这条关系是否有阅读价值。
16. As a 研究者, I want 在有数据时查看共同参考文献, so that 我能了解两篇论文共享的研究基础。
17. As a 研究者, I want 摘要缺失和仅按标题计算时得到提示, so that 能谨慎理解相似结果。
18. As a 研究者, I want 默认看到简洁的画布和选中论文的邻居, so that 不会被全量标签和连线淹没。
19. As a 研究者, I want 搜索标题或作者并按年份、来源筛选, so that 可以快速定位需要的论文。
20. As a 研究者, I want 列表、画布和详情的选择同步, so that 不会丢失阅读对象。
21. As a 研究者, I want 拖动、缩放、适应画布和定位起点, so that 能方便探索局部关系。
22. As a 研究者, I want 筛选和切换关系层时位置稳定, so that 我能保留对地图的空间记忆。
23. As a 研究者, I want 查看完整标题、作者、摘要及可信论文链接, so that 能直接开始阅读。
24. As a 研究者, I want 图谱库与地图详情保持统一视觉风格, so that 使用过程连贯清晰。
25. As a 研究者, I want 在窄屏设备上切换图谱、列表和详情, so that 内容不会被压缩到无法阅读。
26. As a 键盘用户, I want 通过列表选择论文并打开关系详情, so that 核心操作不依赖拖动或悬停。
27. As a 对动效敏感的用户, I want 页面尊重减少动态效果的设置, so that 布局动画不会影响阅读。
28. As a 研究者, I want 区分没有数据、查询失败、缓存回退和额度截断, so that 不会把获取限制理解为没有相关研究。
29. As a 研究者, I want 查看每类数据的获取时间与完整性, so that 能判断是否需要重新生成。
30. As a 研究者, I want 刷新失败或取消后仍能打开上一次完整地图, so that 已有结果不会损坏。
31. As a 研究者, I want 大图计算时页面保持响应并显示状态, so that 等待时仍能操作界面。
32. As a 研究者, I want 旧图继续可读并明确标记历史数据, so that 升级不会丢失已保存的探索结果。
33. As a 研究者, I want 关闭生成功能后仍能查看已有图谱, so that 功能设置具有可预测的含义。
34. As a 维护者, I want 从真实入口验证生成、取消、兼容和页面交互, so that 测试覆盖用户实际遇到的行为。
35. As a 维护者, I want 用固定样本检查漏检、误连和展示稳定性, so that 后续算法升级有比较依据。

## Implementation Decisions

### 1. 产品边界与模块职责

- 沿用相关工作地图、起点论文、引用关系、内容相似、推荐来源、关联依据和图谱快照等领域用语。参考文献不自动称为“关键前作”，引用论文不自动称为“继承工作”。
- 保留现有 CitationExplorer 的生成入口、返回可打开结果的契约，以及 Web 后台任务和 CLI 调用方式。将外部数据协议、图谱构建与页面渲染分为内部职责；不以重构整个应用作为前置条件。
- 任务捕获提交时的研究方向、明确条件、配置和预算。运行中切换方向不改变该任务语义；图谱库和缓存复用继续遵循方向隔离。
- 地图是探索结果，不写入正式推荐快照，不因查看或生成修改阅读状态。已有“不相关”标记排除非起点候选；起点若被标为不相关或违反方向条件，保留为明确的探索参照并提示，不能被当作符合条件的推荐。
- 首版支持生成和重新生成完整快照。点击任意节点无限扩展、自动构建整个个人论文库地图不在本次范围内。

### 2. 候选覆盖、方向判断和预算

- 分离候选预算和展示预算。新配置默认最多收集 150 篇非起点候选，每个来源最多 50 篇；默认展示最多 50 个节点，包含起点。首版可调展示范围为 1 至 150，候选总上限为 500，并校验展示额度与候选额度关系。
- 已有配置中的来源数量保留为该来源的候选上限；新增展示与总预算采用兼容默认值，不静默扩大用户已经保存的请求规模。设置页明确区分候选额度与展示额度。
- 每次生成默认最多 20 次外部请求，包含起点查询、分页、交叉引用和重试。按服务实际契约分配批次和分页额度；预算耗尽立即停止扩展并标记截断。重试不能绕过总额度，不能通过静默缩小单页数量产生额外无界请求。
- 基础来源按轮次分配请求，避免一个高被引来源耗尽其他来源的首次获取机会。优先取得起点及各来源第一页，再补页；为展示节点的交叉引用补全预留额度。总候选与各来源上限作用于去重后的论文，接口返回重复记录仍消耗请求额度。
- 去除固定计算机领域作为产品边界。外部适配器在实施时核实服务支持的跨领域参数；服务不能提供的覆盖范围必须在状态中说明，不能把受限数据标为全学科覆盖。
- 方向主题线索参与相关性排序，偏好条件影响排序。必要条件和明确排除条件复用项目已有条件语义；仅有词汇缺失或背景提及不能作为硬淘汰证据。需要语义判断且当前能力无法验证的候选标为待判断，放在独立候选列表，默认不进入符合方向的地图。
- 无研究方向时以起点标题、摘要和已获取关系为依据。有方向但无足够合格候选时显示较小地图及原因，不自动放宽明确条件或回退为不受约束的全领域结果。
- 对合格候选以起点和方向相关性为主要依据，近似重复惩罚提供多样性。默认预留最多 20% 的非起点展示名额给近三年且通过相关性门槛的工作；没有合格近期工作时回归普通排序。年份未知不假装为近期，高引用数不作为相关性的替代。
- 相同输入和算法版本的选择结果可复现，平分时用稳定论文身份排序。候选来源顺序改变不应产生不同结果；记录入选理由、未展示数量和预算摘要，避免把图当作完整领域地图。
- 身份合并优先使用可靠的服务论文身份及明确外部标识映射，不仅凭相近标题合并。保留多来源角色，采用更完整的有效元数据，并记录缺失字段。

### 3. 关系模型与关联依据

- 持久化有方向的真实引用和无方向的内容相似，推荐来源属于节点来源信息。相同论文对可以同时存在引用和相似关系，前端分别编码，不能相互覆盖或猜测转化。
- 相似边只接受有限、正值且达到有效阈值的分数，禁止自环。首版沿用 0.025 作为可校准初始阈值和每节点最多选择四个相似邻居的默认策略；合并为无向边后实际度数可以超过四。没有达标邻居时保留孤立节点，不强制补边。
- 首版保留标题加权、摘要辅助的本地词汇相似度，规范大小写和常见连字符。对分词不支持的文本或缺少有效词的论文明确显示依据不足，不能把“无法计算”冒充“内容完全不同”。记录算法版本及其适用范围。
- 在同次生成中以固定的合格候选集合建立词汇权重，再选择展示节点和计算边；浏览器筛选不重算分数。身份去重、缺失文本处理及相似度语料范围写入快照元数据，保证解释与实际计算一致。
- 相似边保留有限个对计算有贡献的共同词或词组。详情使用“内容相似（词汇估计）”，说明只适用于本次快照；分数不是概率。短摘要、缺摘要和仅标题计算有独立标记。
- 引用箭头始终从引用方指向被引用方，详情以完整标题确认方向；说明引用来源和获取时间，不将引用自动解释为支持、改进、反驳或方法继承。
- 在已取得参考文献数据时计算并列出共同参考文献，作为独立依据，不冒充文本相似分数或直接引用。数据不完整时显示“已获取数据中的共同参考文献”，零个结果不证明没有共享研究基础。
- 引用补全以最终展示节点为主要范围；引用详情需要的有限共享参考标识可随已有批量请求获取。不得为每条相似边另发请求形成无界扩张。

### 4. 图谱快照、故障与兼容

- 快照增加显式格式版本、快照身份、起点、方向身份及条件签名、生成时间、算法版本、有效预算、节点、不同类型关系与来源状态。来源状态分别表达成功、成功但无结果、部分成功、缓存回退、失败和预算截断；截断可以与成功或缓存并存。
- 起点、各候选来源和交叉引用分别保留实际获取时间、尝试时间、数量及完整性。缓存回退不更新原获取时间；页面汇总状态，并允许展开来源明细。
- 缓存仅复用身份、方向及来源范围兼容的数据。旧候选可以按当前条件重新筛选，过时的方向判断和排序不能直接视作当前结果。部分交叉引用失败时按已成功获取的论文范围合并缓存，不能仅以“存在一条新交叉引用”判断全部补全成功。
- 起点查询失败且无可信缓存时生成失败；起点可用但其他来源失败时可以发布明确标记的部分结果。全部候选来源失败与真实成功零结果使用不同提示。
- 使用有界的请求超时、退避和取消检查。可恢复的限流、连接故障和服务器错误在预算内重试，明确的无效输入和不存在响应不反复请求。等待期间允许取消，并避免把整段退避时间占用在共享服务锁内。
- 将图数据、页面及必要资源准备为同一不可变快照，完成校验后通过单一活动快照引用切换发布；图谱库和页面始终解析同一快照。发布前取消或失败保留旧结果，发布完成后不得再将该已提交结果报告为未完成取消。
- 同一方向同一起点的重复提交沿用任务去重；发布时处理并发竞争，不能混合两个任务的文件。首次生成失败不得留下可被图谱库误认为完成的半成品。
- 功能禁用由生成服务与入口共同执行，禁止创建新图谱，已有图谱保持可读。参数校验和陈旧方向保护沿用项目现有行为。
- 旧格式读取采用兼容适配，历史时间或来源缺失标为未知。旧推荐连线从引用层移除，旧零分相似边从新版展示中排除；适配不静默覆写原始历史文件。未知的未来格式返回清晰的不可读提示。
- 旧图链接在应用内通过安全读取和新版渲染保持可用；独立旧 HTML 文件不能宣称会自动升级，用户重新生成后才得到新展示与新状态。保存的新图仍支持本机直接打开，所需资源本地可用，不依赖公共 CDN。

### 5. 展示页视觉与交互

- 整体采用与 PaperLoom 一致的温暖浅色背景、白色面板、深灰正文及克制的橙色强调。起点用橙色和专属标记，选中节点用清晰外环；颜色与图例、形状或文字共同表达状态。正文和控件以 14 至 16 像素为基线，避免把论文信息压缩为小字。
- 宽屏采用可折叠三栏：左侧约 280 像素论文列表，中央弹性画布，右侧约 340 像素详情；1366 像素宽时中央仍至少保留 600 像素。顶部显示起点、方向、节点计数和数据状态，次要筛选收进展开面板。
- 主工具栏仅保留搜索、内容探索/引用脉络切换、筛选入口及视图操作。画布背景仅用低对比底纹，边线使用较低透明度，面板采用细边框、统一圆角及少量阴影，避免与图谱争夺视觉注意。
- 默认内容探索视图展示所有可见节点，突出起点邻居，弱化非邻居；仅起点、选中节点及其少量邻居优先显示标签。提供“全图关系”和“显示标签”控制，密集时仍做标签避让，完整标题始终可在列表和详情读取。
- 节点大小使用有上下限的引用数映射；缺失引用数与零引用区分。年份使用可辨的连续色阶，未知年份单独标识，起点和选中样式不能被年份编码覆盖。图例说明大小不等于相关性，位置只辅助表达关系。
- 相似边用无箭头实线，引用边用不同线型和箭头；切换引用脉络时仅显示已证实引用。选中同一论文对存在两种关系时，详情分别列出其含义和依据。边的交互热区大于视觉线宽。
- 列表默认按与起点及方向的相关性排列，可切换年份或引用数；卡片提供标题、作者、年份、来源及简短入选依据。搜索标题/作者、来源多选、年份范围和最低引用数共同过滤，显示可见数与总数，并支持一键清除。
- 起点固定保留作为参照，搜索/筛选命中数单独说明不包含这个例外。选中普通节点被过滤后，选择回到起点并告知用户；列表、画布和详情保持同步。
- 详情按“论文信息 → 为什么相关 → 摘要 → 打开论文”组织；可切换论文详情与关系详情，来源状态按需展开。仅展示可以从已取得数据证实的关联，候选入选理由与两篇论文之间的关系分开。
- 筛选、选择和关系层切换复用已计算坐标，不重复随机布局。缩放和拖动使用实际图形坐标变换，适应画布按可见节点边界计算；提供定位起点、适应画布和重置视图，拖动结束不误触节点选择。
- 引用脉络首版复用坐标以保留空间记忆，通过方向与焦点呈现关系，不承诺时间因果树。重新生成后的节点集合可以变化；相同快照重开应获得稳定初始布局。
- 小于 1200 像素时详情改为可关闭抽屉，优先保留画布；小于 768 像素时提供图谱/列表切换，详情为全宽面板。页面不产生整体横向溢出，触控设备可通过按钮缩放，关键点击目标至少 44 像素。
- 列表和所有控制支持键盘，焦点清晰；抽屉/对话框有标题、关闭键和焦点返回。核心关系解释可从列表进入，不能只依赖悬停。普通文字对比度至少 4.5:1，重要图形及焦点至少 3:1，并尊重减少动态效果设置。
- 布局在后台或分帧执行，使用收敛条件和计算上限，移除启动时无间断的固定长循环。首屏先提供标题、列表及状态，布局完成后淡入或直接显示；计算超时提供稳定回退位置，不伪造关系或丢失列表。
- 图谱库沿用同一视觉系统，展示起点标题、方向、实际节点数、更新时间和完整/部分/历史未知状态。生成表单显示预算说明和当前方向，已有快照可以打开或重新生成；无需先打开地图才能发现来源失败。
- 空结果、仅起点、全来源失败、部分缓存、筛选无命中、布局计算中及布局失败均有专门状态与可行下一步。页面正文不暴露内部调试堆栈。

### 6. 交付顺序

- 第一阶段完成关系语义、预算分离、方向约束、来源状态和一致性发布，提供确定性样本。
- 第二阶段完成图谱页与图谱库改版、关系解释、响应式交互和后台布局。
- 第三阶段完成历史兼容、故障和取消验收、固定质量样本及浏览器视觉检查。交付完成必须同时满足生成与展示验收，不能只替换配色或只更新后端。

## Testing Decisions

- 主验收边界采用本地 Web 应用真实生成入口：提交任务、等待可观察终态、读取图谱库和产物，再打开生成页面。只在外部 HTTP 传输处使用固定响应，真实执行配置、方向判断、图谱生成、存储和渲染，不替换整个 CitationExplorer 验收本功能。
- 复用已有 Web TestClient、临时目录、后台任务测试和图谱 HTTP MockTransport 做法。补充少量直接生成入口测试以覆盖 CLI 共用契约；无需为了测试拆出大量公共接口。
- 浏览器验收直接访问上述流程产物，使用本地固定样本。测试关注选择、过滤、箭头含义、关系解释、故障提示和阅读可用性，不锁定内部辅助函数、CSS 类名、模板全文或节点精确坐标。
- 验收场景如下，使用固定输入证明外部结果：

1. 完全无共同有效词的论文不产生零分相似边，孤立节点仍可选择和打开。
2. 推荐服务给出论文但没有引用证据时，引用层不显示推荐线。
3. 同一论文对既有引用又有相似关系时，两种关系均可查看，箭头方向正确。
4. 多来源返回同一论文时只展示一个节点，所有来源保留，预算按约定计数。
5. 一个来源有多页大量结果时，其他来源获得首次获取机会，候选与请求总量受限并显示截断。
6. 相关跨学科论文可入选；仅背景提及主题或排除词不会被误当作主题判断依据。
7. 明确不满足必要条件或符合排除条件的非起点候选不进入地图；无法判断者在独立候选列表说明原因。
8. 起点与方向冲突、无方向、方向切换以及同论文不同方向分别保持规定语义和隔离。
9. 近似重复候选不会占满固定样本，合格近期工作得到预留机会；无合格近期工作时不强行凑数。
10. 缺摘要、缺年份、缺引用数和不支持的文本显示正确状态，不能形成 NaN、无穷大或伪造解释。
11. 成功零结果、404、超时、限流、服务器错误、缓存回退和预算耗尽可区分；缓存获取时间不被刷新伪装。
12. 部分交叉引用成功时仍可正确复用其余兼容缓存，并标出不完整范围。
13. 生成新快照时在请求、等待、渲染及发布前取消，旧图谱库与旧页面仍一致；首次失败不产生完成条目。
14. 发布完成的结果和任务终态一致；并发相同任务不造成跨快照文件混用。
15. 禁用功能同时限制 Web 与直接生成入口，已有图谱仍可访问。
16. 旧格式加载移除错误关系、保留历史数据并显示未知状态；未知未来格式和损坏文件给出可理解提示。
17. 搜索、组合筛选、清除筛选、排序及选择在列表、画布和详情保持一致；起点例外明确。
18. 相似/引用视图切换和筛选不打乱坐标，定位、缩放、拖动及重置在不同宽高比下正确。
19. 关系详情可通过键盘入口打开，抽屉关闭恢复焦点；减少动态效果设置被尊重。
20. 打开 HTML 特殊字符、超长标题、空摘要及不可信链接样本时，文本安全呈现，外链仅允许受支持安全协议。
21. 单节点图、150 节点图、高度密集图以及布局超时均保留可操作列表，界面不会无限等待。
22. 本机直接打开新图与应用内打开都能加载必要资源，现有应用内容安全策略下功能正常。

- 视觉验收覆盖 1440×900、1366×768、1024×768 和 390×844，检查正常、节点选中、关系详情、空结果、部分数据和长标题状态。截图用于人工检查留白、层级、遮挡和溢出；初版不把像素完全一致作为唯一通过条件。
- 性能验收使用固定 50 和 150 节点快照，记录浏览器版本及机器配置。排除网络和冷启动因素后，以列表和工具栏 1 秒内可交互、初始布局 3 秒内完成或给出稳定回退、交互反馈 200 毫秒内为目标；测量不达标需优化或明确记录限制，不能以设定上限冒充实测成绩。
- 质量样本包含同词不同主题、表达不同但相关、跨学科相关、经典工作、新近低被引、摘要缺失和完全不相关论文。记录候选覆盖、误连、硬条件误判与来源完整性；对首版词汇算法无法处理的语义差异记录已知限制，不预设它能解决所有同义表达问题。

## Out of Scope

- 新增付费模型依赖、训练嵌入模型、建立向量数据库或全量学术搜索服务。
- 自动判断论文支持/反驳/继承关系，自动命名研究流派，或把图形聚集直接宣称为经验证的学术分类。
- 无限多跳扩展、全个人论文库地图、协同编辑和在线共享平台。
- 自动修改收藏、不相关标记或推荐记录，以及图谱触发的邮件、Zotero、Obsidian 外部写入。
- 全面重做应用其他页面、暗色主题、三维图谱、PNG/SVG 导出和另建浏览器测试平台。
- 保证获取完整引用网络、证明引用因果或承诺尚未测量的召回提升。

## Further Notes

- 用户已接受主目标为发现后续阅读、辅助查看引用脉络，以及跟随研究方向并允许跨学科关联的建议，并明确要求改善展示页观感。
- 本文的数量、布局断点、色彩方向、筛选细节和性能目标是为推进实施选定的可逆默认方案，不代表已经完成实现或测量。若实施验证发现服务限制，保留产品语义与预算边界，并记录具体差异。
- 测试沿用前述最高层入口和外部请求替身，增加对本次新增页面行为必要的浏览器验收；该方案落实用户“按推荐进行”的授权。
- 本规格先明确首版可交付行为。后续文本嵌入实验应与本地基线在同一固定样本上比较，评估质量、延迟、成本与隐私后再决定是否采用。
