# 三款研究工具的内容职责与关联边界

PaperLoom 负责发现、筛选和生成阅读辅助材料；Zotero 负责文献、PDF 与阅读批注；Obsidian 负责个人理解、跨论文关联和研究写作。现有 PaperLoom 个人笔记与阅读功能继续可用，本决定不要求迁移历史数据。用户已在设计讨论中接受这一职责分配。

本期以明确的跨应用关联和单向托管内容更新建立协同，沿用现有资料组织方式，不把三端内容建模为任意双向覆盖的副本。双向同步虽然能减少部分手动搬运，但会引入个人编辑、论文修订版和生成报告之间的冲突及删除传播语义；这些成本不应隐含在首次收录中。Zotero 条目可跨研究方向复用，研究方向的阅读状态和 Obsidian 笔记仍保持现有隔离。
