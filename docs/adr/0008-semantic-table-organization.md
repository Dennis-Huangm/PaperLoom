# 0008：模型整理表格语义，程序保存和展示数据

已采用，2026-10-07。原有规则将等号、标题包装和引用差异误判为不同实验条件，造成重复表格及表注；改为在分片摘录后、正文合成前进行一次整篇模型整理，由模型决定表题、中文表注、实验变体和重复行归属，程序仅按已有行编号取用原值并检查引用结构。原始摘录及模型选择方案随表格目录保存；整理不可用时回退到现有可读表格，取消仍正常传播，不为整理错误重试、不添加正文诊断、不阻断报告交付。

此决策补充 ADR 0007：允许一次可选的内容编辑调用，但不恢复事实或数值审计、模型互相核查及发布裁决。代价是增加模型延迟与语义误判可能；通过提供全部摘录及相关原文上下文、保留恢复材料降低影响，而不通过不断扩充语义正则规则或第二套核查器解决。
