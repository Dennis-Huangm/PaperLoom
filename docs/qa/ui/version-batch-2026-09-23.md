# 批量版本同步验收

使用 `work/preview_version_batch.py` 的隔离数据与离线 arXiv 替身，未请求真实论文、模型或外部集成。

- 桌面默认视口和 390 × 844 窄屏检查：待同步清单、全选控件、选中数量、预览对话框和操作按钮均可读、可用。
- 勾选三篇，默认不生成报告、不导出。预览列出三篇固定 v3 目标、三份 PDF 校验/下载范围、零份报告。
- 执行时模拟第二篇 PDF 下载失败。其他两篇成功，批次显示 2/3，清单只剩一篇。
- 展开批次，点击“继续未完成论文（1 篇）”。完成后批次显示 3/3，待同步清单归零，三篇收藏和本地 PDF 均为 v3。
- 自动化覆盖取消与恢复、进程丢失后复用产物、查询失败隔离、配置与版本固定、重复提交合并、方向隔离和旧批次恢复入口。

报告数量与笔记摘要数量描述模型工作的论文范围，不代表固定调用次数。真实外部服务连通性和模型质量不在本次离线验收范围内。
