# 备份与独立目录恢复验收记录

日期：2026-09-25。桌面/窄屏视觉验收按用户要求留待之后，本轮未调用浏览器工具。

## 已验证

- 新增 15 项备份测试场景，使用隔离目录、假论文/笔记和假凭据。默认包不含 .env、报告、PDF 或搜索缓存；完整包包含显式选择材料，PDF 单独选择时附带元数据；运行时环境变量值不进入 ZIP。
- 往返恢复后笔记内容和阅读版本不变，源文件不变；配置输出迁移到 run，任务请求的项目/输出目录指向恢复副本。
- 保留和替换按文件处理，额外文件保留；替换前的完整目录可检查。目标或备份在预览后变化时拒绝执行。
- ZIP 损坏、清单不匹配、SHA 不匹配、路径穿越、Windows 设备名/ADS、大小写冲突、链接和大小限制均拒绝。
- 模拟第二次目录重命名失败，原目录回滚；模拟进程在旧目录改名后退出的磁盘状态，显式整理可以放回旧目录。未将这项模拟称作真实进程崩溃测试。
- GUI 占用目标时不能恢复，恢复持有目录外占用锁时不能启动该副本 GUI；已有任务持久化测试通过。
- FastAPI TestClient 验证配置页入口、创建、下载、预览、恢复、旧方向拒绝及 no-store。CLI preview/restore 可往返。
- 全量 324 passed / 1 warning（52.80s）。编译、JavaScript 语法、依赖一致性和差异格式检查通过。

## 第一版边界

恢复至 restored 下的独立副本，不原地覆盖运行环境。ZIP 不加密，.env 明确 opt-in；保留模式不合并 JSON 字段；外部库不打包、不触发同步。CLI 等其他写入需停止，容量上限和手动中断整理见 README。
