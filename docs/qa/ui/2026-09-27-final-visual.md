## 发现并修复

1. **推荐摘要/推荐依据没有解析公式与 Markdown。** 通过共用 Markdown 渲染器和 HTML 净化生成展示内容，KaTeX 本地渲染；切换论文时克隆已净化的模板并重新渲染。文献库的公开摘要和保存价值同样接入，个人笔记保持原有文本处理。摘要不引入远程图片或活动 HTML。
2. **报告目录出现原始数学命令。** 目录保留公式 token 供 KaTeX 渲染，原标题锚点不变；不复制标题中的活动 HTML 或嵌套链接。
3. **短行内公式出现多余小滚动条。** 为数学容器预留字形边缘空间，消除上下标导致的轻微溢出；长公式仍可局部滚动。
4. **桌面宽结果表的依据列逐字竖排。** 共用报告表格设置可读的最小列宽，末列至少 10em；超宽表在自身区域内滚动。RULER 最末列恢复到 140px，行高明显降低，整页没有被表格撑宽。

实现：`render.py`、`markdown_rendering.py`、Web 模板及 `app.js/app.css`；静态资源版本更新为 `20260927-summary`。新产物自动使用；通过 GUI 打开的旧报告从 Markdown 应用共用渲染。独立旧 HTML 不会自动被改写。
