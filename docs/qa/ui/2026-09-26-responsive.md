## 发现并修复

1. 推荐筛选栏 flex 项被压缩，出现按钮文字相互重叠：保留按钮自然宽度，在既有横向滚动区浏览。
2. 窄屏报告列表操作挤在一行、文字被拆开：操作按完整按钮换行。
3. 文献库搜索输入框被进度筛选和提交按钮挤占：窄屏改为两行，搜索词一行，进度和提交一行；保留清除入口。
4. 带收藏按钮的报告顶部控件挤压品牌和文字：480px 以下使用两行固定高度布局，目录面板相应下移。
5. 长报告窄屏整页滚动宽度为 763px，而可视内容只有 375px：为正文及数学区域建立定位边界，长公式在自身区域内滚动；行内长公式同样有宽度限制。修复后页面宽度与滚动宽度相等。
6. 长代码标识符、网址被正文裁掉：普通正文允许必要的断行；代码块继续局部滚动，公式不按普通文字拆开。
7. 比较矩阵维度列逐字竖排、论文文字列过窄：第一列设最小可读宽度；Markdown 解析器识别既有“维度 / P1 … P5”表头契约并添加比较矩阵样式类，论文列至少 260px。窄屏局部滚动，不压缩整张表。

上述修复位于共用 CSS、报告样式和 Markdown 渲染器。新增报告自动应用；GUI 打开历史报告时从 Markdown 应用当前样式。独立旧 HTML 的内嵌样式需要重新渲染，本次仅刷新此前分享的 grounded-synthesis 和 long-synthesis-balanced 两份测试 HTML；两份 report.md 的 SHA-256 均未改变。
