# 版本同步页面验收

使用 `work/preview_version_sync.py` 启动隔离的本地服务。数据和 PDF 均为离线生成的样例；未访问真实 Zotero、vault 或模型服务。

- 窄屏默认视口及 1440 × 1000 桌面视口：输入、可选同步项、任务状态、四项版本指标和结果入口可见，卡片正常换行。
- 初始状态：收藏 v1、远端 v3、PDF 下载失败；页面显示失败阶段及“继续 v3 未完成步骤”。
- 点击继续：后台任务成功；刷新状态后，本地 PDF 和收藏均显示 v3，失败按钮消失，结果页面入口可用。
- UI 自动化完成后关闭临时标签并恢复默认视口。

离线自动化另覆盖报告回退、部分失败后重试、取消、目标版本固定、方向隔离、追踪轮询和旧文件/手写内容保留。真实外部服务的可用性不属于此次验收结果。
