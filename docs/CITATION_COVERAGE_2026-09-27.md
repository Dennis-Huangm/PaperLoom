# 引用覆盖与局部隐藏改进

日期：2026-09-27。承接 RULER 真实报告验收，本轮仅使用已保存的模型输出和 PDF 页面文本，无新增模型请求或外部操作。

## 原因与处理

RULER 的 VectorFusion 行含 `31.4k` 等 token 数量。旧行解析器不识别该后缀，无法完整识别源行；模型引用又从该行中间开始，造成前 3 个正确数字被隐藏。带后缀的数字还可能使相邻模型错配检查失效。

现在 `k` 被保留为明确后缀：`31.4k` 不等于 `31400`，不做隐式换算。完整引用只能在以下条件全部满足时补充：

- 原引用有经过校验的页面文本偏移，并与候选源行实际相交。
- 模型名及已能识别的条件相符，候选行位置唯一。
- 行顺序或明确列对应检查通过；存在错值、错序或条件冲突时不补充。
- 精确范围仍满足现有 Q1 摘录长度、页面及文档哈希约束。

新增 Q1 引用附在原引用旁，原引用保留，补充记录保存到 `numeric_audit.completed_row_citations`。此操作不改写任何数值，也不把复杂表头的行顺序检查提升为指标列核验。

复现参数此前以整段为隐藏单位。现在仅对公式、代码、引用文本及括号外的显式分号识别子句，每个含数字子句必须有自己的完整引用。缺少依据的数字不能借用兄弟子句引用中碰巧相同的数字。保留原有非数值文字，不生成替代结论；无法可靠切分时仍隐藏整个定量段落。括号里的数据集明细不会被切成缺少条件的片段。

提示词同时要求跨片段的数据行保留完整引用、复现参数按子句就近引用。此提示词效果尚未用新模型响应测量；本轮回放评估的是确定性处理效果。
