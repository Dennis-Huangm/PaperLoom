# PaperLoom v1.6.0 · 报告保全与后台阅读

2026-10-03

本版改进全文报告的数据保全、阅读导航和后台运行，让已提取的实验数据在正文整理、引用核对及网页渲染后仍可完整查阅。

## 主要更新

- **原文表格保全**：正文负责实验解读，程序从冻结数据呈现表格。同一表号只展示一次，不同实验条件保留独立变体；数值引用修复不改写原有正文或矩阵。生成目录保存 `tables.json`、`report-draft.md`、`table-preservation.json` 和证据详情，发布检查失败时保留恢复材料。
- **表注与原文页面**：表题和说明统一整理，保留模型名、数字、单位、条件与独有脚注。定性示例和未提取矩阵在相关讨论处提供可展开的原文页面，同页示例共用图片。
- **报告阅读导航**：目录与本地论文侧栏支持收起，论文侧栏可搜索、切换和调整宽度。长表可在对应讨论处展开，打印时自动包含全部矩阵。
- **Windows 后台启动**：新增普通用户登录任务，无终端启动网页服务；提供正常停止、重启、状态和日志入口。已有 NSSM 服务可通过一次性管理员操作迁移，保留原注册及启动方式记录。
- **任务并行设置**：在任务队列旁选择 1–8 个并行任务，立即保存并生效；调低上限不会中断正在运行的任务。
- **渲染与恢复修复**：改进中文粗体、公式与原文引用、美元金额表格和基本信息呈现；任务完成状态在报告及配套文件保存后更新，阅读脚本更新后刷新缓存。

## 安装与升级

普通用户下载 **`paperloom-1.6.0-source.zip`**。需要 Python 3.11+；Windows 解压后运行 `Setup-PaperLoom.cmd`，安装完成后运行 `Start-PaperLoom.cmd`。Linux / macOS 按 README 建立虚拟环境。wheel 用于已有 Python 环境，网页依赖需安装 `[gui]`。附件提供 `SHA256SUMS.txt` 供校验下载。

升级前等待任务完成，停止旧服务与调度，备份 `.env`、`config.yaml`、`profiles/` 和输出目录，再在新版目录迁移数据并重新安装。已有配置不会被模板覆盖，历史报告和兼容入口保留。

如已启用 Windows 登录任务，先从旧目录停止后台服务，再从新目录重新注册并启动，使计划任务指向新版安装。无终端启动、日志、停止和旧服务迁移的命令见 [CLI 文档](CLI.md)。

新生成报告采用表格保全流程；历史报告继续可读，不会在升级时自动重新生成。

## 使用范围

网页面向本机单用户使用，默认地址 `http://127.0.0.1:8000`。联网检索和模型功能需要对应服务可用。

表格保全检查确认处理链没有损坏已提取数据，不证明 PDF 的全部内容都已提取，也不证明所有数值与结论正确。原文页面和引用提供核对入口；自动核验能力的限制保存在 `evidence.json`，明确引用冲突局部标注，已有实验数据继续保留。
