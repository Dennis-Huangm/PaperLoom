# PaperLoom v1.5.0 · 网页研究工作台

2026-10-01

本版集中整理 v1.4.0 之后的研究工作流，让研究方向、每日推荐、会议补读、全文报告、相关工作探索和跨工具收录都能在本地网页中完成。

## 主要更新

- **研究方向草稿**：从主题与参考论文生成可编辑方案，区分主题线索、偏好、必要条件和排除条件；支持试搜、参考检查、保留手动修改及删除恢复。最近 5 篇收藏可引导补充检索，推荐详情提供依据。
- **会议论文检索**：选择 ICML、NeurIPS、CVPR、ICLR、ACL 及会议年份，关联 arXiv 后收藏与阅读；支持当前方向、临时主题、浏览目录，以及长期的最新 arXiv、会议论文和混合推荐模式。来源状态区分未公布、未关联、不确定、失败和预算截断。
- **相关工作地图**：围绕起点论文探索引用和内容相似，展示关联依据、方向匹配、来源状态与未知条件；生成失败或取消时保留原完整地图。
- **Zotero / Obsidian 收录**：统一“收录与同步”入口，确认版本与材料、选择目标并保存逐目标回执；检查已有条目和历史托管笔记，继续未完成操作，保留个人编辑。
- **网页界面**：改进周报、追踪、图谱、搜索和收录页面；推荐筛选使用圆角分段选中态与数量徽标；会议检索按范围、主题、选项分区，适配窄屏。
- **可靠性与维护**：PDF 续传、取消和可选 Windows curl 分段下载；共享 API 限速与冷却；保留报告证据并修复表格渲染。任务历史清理和推荐清除提供明确范围，保留收藏与阅读材料。
- **安装与文档**：Windows 提供双击安装、启动入口。README 聚焦网页工作流，命令行与自动化单独成册。用户源码包仅包含公开运行资料，并提供 wheel 和 SHA-256 校验文件。

## 安装与升级

普通用户下载 **`paperloom-1.5.0-source.zip`**。需要 Python 3.11+；Windows 解压后运行 `Setup-PaperLoom.cmd`，安装完成后运行 `Start-PaperLoom.cmd`。Linux / macOS 按 README 建立虚拟环境。wheel 用于已有 Python 环境，网页依赖需安装 `[gui]`。

升级前停止旧服务，备份 `.env`、`config.yaml`、`profiles/` 和输出目录，再在新版目录迁移数据并重新安装。已有配置不会被模板覆盖，历史报告和兼容入口保留。

**新配置**默认关闭邮件、Zotero、自动周报和自动版本检查；完成手动体验后按需开启。此调整不修改旧安装的配置。备份恢复副本默认暂停调度。

## 使用范围

网页面向本机单用户使用，默认地址 `http://127.0.0.1:8000`。联网检索和模型功能需要对应服务可用；会议目录不保证完整覆盖，关联的 arXiv 修订版也不保证与正式出版版本完全相同。报告提供辅助阅读与原文定位，关键结论应核对原论文。
