## 可复现的问题与修改

旧整合过程逐分片取已引用原文，直到 32,000 字符预算用尽。本例前部内容占满预算后，所有物理第 14–19 页的 ID 被替换为不可用提示。第 8 个分片实际上已经提取 CCR/rMSE 及正确 ID，丢失发生在整合输入的构造阶段。

`cited_span_material` 现在在固定预算内先为带公式的笔记段落分配最多一半空间，再按被引用的物理页面轮流分配剩余空间，最后按原文顺序输出。由此避免前半篇或单页长文本独占预算。优先选择不代表公式已被语义验证；过期/未知 ID 仍不可用，未入选 ID 仍被明确降级，不扩展为模糊匹配。

离线重放验证：8 次分片 system/user 输入逐字与已保存请求相同；新整合保留 67 个片段、31,700 个原文字符，覆盖 16 个有引用的物理页面，两条附录公式 ID 均保留。保持原 32,000 字符上限，没有通过无界增加上下文解决问题。

最终整合提示新增两项约束：公式本身必须保留其出处；趋势须检查同一模型、指标的相邻难度并保留反例。结果表建议选择与结论相关的代表性行，避免无差别复制全部基线。这些是生成约束，不是可靠的自动语义证明。

### 表格数值校验漏洞

审阅发现既有数值审核仅在段落以 `|` 开始时逐行处理表格。模型把表格紧接在说明文字、三级标题或列表项后时，多行被作为一个整体，某行可借用别行的引用，导致漏报。新增失败回归复现“B 行无依据但借用了 A 行的相同数值”，然后修复：不依赖空行，逐行分离表格；预先保护多行原文 token，防止原文内的空行或竖线被误当表格边界。
