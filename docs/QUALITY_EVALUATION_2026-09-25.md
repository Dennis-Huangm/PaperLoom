# 报告与跨论文比较：质量评估及改进

日期：2026-09-25。此次评估使用合成论文材料、固定模型响应与本地 PDF，不调用真实模型或外部服务，不读取个人研究资料。桌面与窄屏视觉验收继续按用户要求延期。

## 结论与范围

原实现能校验原文摘录的位置和比较引用的论文归属，但会放行“引用编号有效、结论数字却不存在”的条目。此次增加局部数值核对、逐项支持摘录与来源层级约束，并修复错误模型 JSON 导致回退再次报错的问题。

本记录评估的是本地质量检查规则，不是模型实际生成准确率。样本为人工构造的正常/错误输出，不是盲测集；全部通过也不能说明真实论文报告无误。

## 用户可见的改进

1. 报告对实验设置、关键结果、可复现性中的数值段落/表格行进行检查。有问题时在开头和报告库提示“实验数值待核对”，末尾列出原陈述、数字及原因；保留原文，避免自动猜测正确值。
2. 比较中的每个保留条目需要同论文来源及连续支持摘录。数值只能由所引摘要/原文摘录支持；仅有模型阅读报告时不接受数值结论，非数值归纳标为推断。
3. 比较附录展示逐项依据与拒绝原因。缺材料、引用错属、摘录不符、数值不符、显式跨论文排名和重复论文结果不继续作为有效结论展示。
4. 模型响应结构错误仍能保存待核对矩阵。检查不增加模型请求次数，不修改历史报告和比较。

## 必须保留的人工核对

固定反例：原文写“Accuracy 91.2%，F1 88.4%”，模型写“Accuracy 88.4%，F1 91.2%”。两种数字都在原文中，当前字面检查会保留该条目；系统明确记录语义支持未检查。

对真实报告，仍需逐项检查：

| 核对项 | 判定依据 |
| --- | --- |
| 指标与数据集归属 | 数字是否来自同一数据集、划分、实验行和模型，指标方向是否一致 |
| 版本与条件 | 是否混用旧修订版、不同训练数据、基线实现或计算预算 |
| 推断与作者结论 | 是否将 may、可能、未讨论改成已证实或不存在 |
| 公式和表格 | 公式是否保留原符号与定义；表格列标题、单位和脚注是否读对 |
| 比较结论 | 是否在条件不可比时仍隐含优劣判断；未知信息是否明确留空 |

未知单位、跨段引用、合法单位换算或自行计算的提升可能被保守标为待核对。公式推导、因果关系、否定词及隐含排名不由这些规则保证。若后续开展真实模型评估，应单独记录公开论文版本、模型与端点、提示词版本、运行配置和人工判读；不要把当前合成规则通过率并入真实模型准确率。
