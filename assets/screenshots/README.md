# 网页端截图

2026-09-27 使用 PaperLoom v1.4.0 的实际浏览器界面截图，未经合成或内容修改。

- `recommendations.jpg`：公开论文推荐材料在隔离演示库中的展示。
- `library.jpg`：示例收藏、阅读状态、标签和笔记；不是个人文献库。
- `comparison.jpg`：选择两篇指定修订版论文的操作界面，未提交模型生成。
- `report.jpg`：此前浏览器验收保存的 RULER 报告阅读界面，包含原论文方法图与生成解读。

论文来源包括 [RULER](https://arxiv.org/abs/2609.25270v1) 与
[SVGenius](https://arxiv.org/abs/2506.03139v1)。论文文字和图示的权利属于原作者，

不作为论文结论准确性的保证。
